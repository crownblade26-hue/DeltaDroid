# DeltaDroid

A multi-system emulator for Android, inspired by Delta for iOS.

Supported systems: GBA, GBC, NES, SNES, Genesis.

Built with Kotlin and libretro cores (mGBA, Gambatte, FCEUmm, Snes9x, Genesis Plus GX).

## Build

GitHub Actions builds the APK automatically on every commit.
Download it from Actions > latest run > Artifacts > DeltaDroid-apk.

## Usage

Open the app, tap "Open game", and pick an unzipped ROM file.
